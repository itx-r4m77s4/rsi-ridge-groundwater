# RSI ridge estimator: groundwater data

Data for the manuscript "Eigenvalue-Scaled Ridge Regression for Collinear Data: A Simulation Study and Application to Groundwater Quality" (Idrees, Chand, Dar, Fatima).

## Contents
- `data/Waterdata.csv`: groundwater quality data from 105 locations in District Sheikhupura, Pakistan (all in mg/L). Response: TDS. Predictors: Calcium, Magnesium, Hardness, Sodium, Sulfate. Originally analysed by Javed, Chand and Ahmad (2021), Desalination and Water Treatment 235, 324-332.
